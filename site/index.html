常见问题

关于 ArchRay 的能力、数据边界、宿主和更新方式，先看这几条。

ArchRay 是什么？

ArchRay 是 AI 优先的架构可视化工具。安装到仓库后，在 AI 助手里输入 /archray，它会读取真实源码并生成可分层、可交互、可离线分享的 3D/2D 单文件 HTML。

会上传我的源码吗？

不会。分析发生在你授权使用的 AI 编程助手会话里，产物保存在本地 .archray 目录；HTML 是自包含离线文件。只有主动执行 update 时才会访问 GitHub Releases 读取版本和校验文件。

支持哪些 AI 宿主？

支持 Claude Code、Cursor、Antigravity、Pi 和 Codex。Claude/Cursor/Pi 使用 /archray，Codex 使用 $archray 或 /skills。安装时可用 --agent all 或逗号列表。

如何安装和更新？

从 GitHub Releases 下载安装包或运行 bootstrap install.sh，安装到目标仓库根目录。安装后使用 ./.archray/archray update --check 检查，再用 update 应用更新；旧版 v0.4 需要一次 bootstrap 升级。

它和普通 AI 架构图有什么区别？

ArchRay 把语义事实和确定性布局分开：AI 记录源码证据与依赖，布局引擎计算坐标和 3D/2D 投影。它强调可追溯路径、离线交付、分层查看、健康度和可替代性，而不是让模型直接画一张不可复现的图。

它适合哪些仓库？

适合需要理解真实分层、跨层依赖、技术债或迁移评估的仓库，尤其是希望把架构图离线分享给团队的项目。它不是运行时监控或自动扫描器；没有源码证据、只靠描述的图需要额外复核。

ArchRay 隐私与数据安全声明

  • 1. 业务源码与图谱 100% 本地零上传 ArchRay CLI 与构建生成的单文件 HTML 完全在本地离线运行，绝不向 archray.dev 或任何远端服务器上传源码、目录名、环境变量或架构数据。
  • 2. 宿主 AI 会话隔离与透明边界 代码审查与架构提取仅发生在你自行授权的 AI 编程助手（Claude Code / Cursor / Antigravity / Pi / Codex）会话内，受你所选模型服务商自身的隐私条款约束。
  • 3. 零埋点、零追踪、全量 MIT 开源可审计 工具链与导出视图不含任何遥测探针或第三方追踪 Cookie；仅在主动执行 update 时只读查询 GitHub Releases 校验 SHA-256。
