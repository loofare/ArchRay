Codex、Pi 与 Antigravity 集成指南

当团队同时使用 Codex CLI、Pi、Antigravity、Claude Code 与 Cursor 时，ArchRay 用统一安装器让所有宿主生成完全一致的 Graph v2 立体架构图。

ArchRay v0.6.0 作者：David Yin · 更新 2026-11-20 MIT Open Source

运行 install.sh 时传入 `codex`、`pi`、`antigravity` 或 `all`，即可按各助手规范写入原生入口（Codex 用 `$archray` 或 `/skills`，Pi 用 `/archray` 或 `/skill:archray`，Antigravity 自动发现 `.agent/skills/archray/`），全员共享同一份 `.archray/graph.json` 规范。

1. 五大 AI 宿主触发语法与部署路径

不同编程助手读取技能与命令的目录约定不同，ArchRay 安装器已全部自动适配：

AI 宿主安装参数会话触发命令写入宿主路径
Codexcodex$archray 或 /skills.agents/skills/archray/SKILL.md
Pipi/archray、/archray-frontend、/skill:archray.agents/skills/archray/ 与 .pi/prompts/
Antigravityantigravity/archray 或自动 Skill 匹配.agent/skills/archray/ 与 .agent/commands/
Claude Codeclaude/archray、/archray:frontend.claude/skills/archray/ 与 .claude/commands/
Cursorcursor/archray、/archray-frontend.cursor/rules/archray.mdc 与 .cursor/commands/

2. 单独安装或全宿主一键部署

支持单宿主安装、逗号多选安装，或传入 `all` 一次性为所有五大助手部署适配器：

安装 Codex / Pi / Antigravity / 全宿主
# 指定单一或多宿主：
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . codex
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . codex,pi,antigravity

# 全宿主一次安装：
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . all

3. 自包含检查更新、SHA-256 升级与卸载

从 v0.5.0 起，项目内 `.archray/archray`（Windows 下生成 `.archray\archray.cmd`）内置完整维护命令，升级和默认卸载均保留用户的架构成果：

项目内维护指令（不污染全局 Node）
./.archray/archray update --check   # 只读检查最新 Release，不改动文件
./.archray/archray update           # 校验 SHA-256 并升级 CLI/Skill（保留 graph/view/HTML）

./.archray/archray uninstall --dry-run  # 预览将被删除的适配器清单
./.archray/archray uninstall            # 移除工具和宿主配置（保留已有图谱）
./.archray/archray uninstall --purge    # 连同 .archray/ 产物一并彻底清除

常见问题

在 Codex 里输入 /archray 没反应怎么办？

Codex 原生技能调用使用 `$archray` 前缀或运行 `/skills` 选择 `archray`，也可直接用自然语言“使用 archray Skill 检查源码并构建架构图”。

Antigravity 如何触发 ArchRay？

安装参数使用 `antigravity` 会写入 `.agent/skills/archray/` 与 `.agent/commands/`，重开会话即可按命令或 Skill 描述触发。

执行 update 会覆盖我辛辛苦苦标注的 graph.json 吗？

绝对不会。`update` 只更新工具链、Skill 与查看器模板，严格保留 `.archray/graph.json`、`view.json` 与 `index.html`。

v0.4 或更早版本如何升级到 v0.6.0？

v0.4.0 及更早版本尚未内置自升级命令，只需在项目根目录重新运行一次最新版 `install.sh`（可带 `. auto --force` 参数），之后即可永久享受 `.archray/archray update`。
