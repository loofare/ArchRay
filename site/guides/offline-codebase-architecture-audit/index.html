Offline Codebase Architecture Audit & Real Benchmarks

Inspecting enterprise repositories requires two non-negotiable guarantees: private source never touches external diagram servers, and large monorepos do not collapse into unreadable spiderwebs.

ArchRay v0.6.0 By David Yin · Updated 2026-11-20 MIT Open Source

ArchRay runs layout and single-file HTML compilation 100% locally inside `.archray/tool` with zero telemetry and zero code upload. On the real `calcom/cal.com` monorepo (7,712 tracked files), ArchRay distilled 33 architectural modules and 75 edges across 7 layers in a 196ms ELK layout, separating measured facts from ≈ estimates and enforcing UTF-8 without BOM.

2. Zero-Upload Privacy Boundary

Traditional SaaS diagram tools upload repository metadata or prompt payloads to hosted web renderers before returning SVG screenshots. ArchRay keeps the entire rendering pipeline offline:

  • Zero telemetry & zero SaaS backend: archray.dev hosts only static marketing pages, documentation, and the FreshMart sandbox.
  • Your AI coding session only reads files you authorize under your existing model provider policy.
  • `.archray/index.html` embeds React, the 3D spatial & 2D Bento renderers, 167 vector tech logos, and the QR poster generator in one portable file that works over `file://` in air-gapped environments.
  • Only explicit `./.archray/archray update` queries GitHub Releases read-only to check `latest.json` and verify SHA-256.

3. Measured Facts vs ≈ Static Estimates & UTF-8 Safety

ArchRay forbids presenting guessed LLM numbers as live production telemetry. Schema fields explicitly annotate each metric’s `origin` (`measured` vs `estimated`, rendered with an `≈` indicator in the UI).

Starting in v0.6.0, ArchRay also hardens cross-platform CJK reliability: CLI validation detects `?` placeholder or `U+FFFD` replacement character corruption, supports decoding GB18030 and UTF-16 inputs cleanly, and requires UTF-8 without BOM output when coding agents write `.archray/graph.json` on Windows.

Frequently Asked Questions

Does ArchRay replace APM tools like Datadog, OpenTelemetry, or Prometheus?

No. ArchRay explicitly distinguishes static repository evidence from runtime monitoring. It inspects repository architecture, file dependencies, and migration options without deploying runtime agents.

Why does the Health Overview panel distinguish measured vs ≈ metrics?

Exact values counted directly from files (like module file count or measured LOC) show verbatim; inferred or sampled complexity/risk heuristics display an ≈ prefix and provenance note so engineers know what to verify.

How does unclipped PNG export avoid chopping off wide layers?

Instead of screenshotting only the current browser viewport, ArchRay re-projects the full 3D or 2D world-space bounding envelope of every node and layer plate cleanly into a high-resolution offscreen canvas.

What does `validate` check beyond JSON syntax?

TypeBox schema validation verifies globally unique node IDs, resolvable edge source/target endpoints, flow steps, bilingual locale coverage when multiple locales are declared, and UTF-8 encoding integrity (catching ??? corruption).
