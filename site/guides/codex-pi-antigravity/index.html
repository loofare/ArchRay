Codex, Pi & Antigravity Integration Guide

Standardize repository architecture maps across polyglot engineering teams using Codex, Pi, Antigravity, Claude Code, and Cursor on one shared Graph v2 contract.

ArchRay v0.6.0 By David Yin · Updated 2026-11-20 MIT Open Source

Pass `codex`, `pi`, `antigravity`, or `all` to ArchRay `install.sh` to install the shared CLI plus each agent’s native trigger (`$archray` or `/skills` in Codex, `/archray` or `/skill:archray` in Pi, and `.agent/skills/archray/` in Antigravity). Every host reads the same `.archray/graph.schema.json` and writes `.archray/index.html`.

2. Install One Host or All Five at Once

Use `--force` with `auto` or explicit comma lists when upgrading legacy v0.4 repositories or adding a new agent host to an already-mapped repo:

Install Codex, Pi, Antigravity, or all hosts
# Specific hosts:
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . codex
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . codex,pi,antigravity

# Install adapters for all 5 supported coding agents:
curl -fsSL https://github.com/loofare/ArchRay/releases/latest/download/install.sh | sh -s -- . all

3. Safe Updates, Check-Only Audits & Clean Removal

Starting from v0.5.0+, ArchRay includes native update and uninstall commands inside `.archray/archray` (and `.archray\archray.cmd` on Windows) that respect user-owned architecture graphs:

Self-contained maintenance commands
./.archray/archray update --check   # Read-only release check vs SHA-256 manifest
./.archray/archray update           # Upgrade CLI & Skills while preserving graph.json & index.html

./.archray/archray uninstall --dry-run  # Preview files before removing adapters
./.archray/archray uninstall            # Keep graph.json, view.json & index.html
./.archray/archray uninstall --purge    # Remove the entire .archray/ directory

Frequently Asked Questions

How do I invoke ArchRay inside Codex CLI or Codex IDE?

Open a new Codex session inside the repository root and type `$archray` or open `/skills` and pick `archray`. Codex automatically follows `.agents/skills/archray/SKILL.md`.

Does Pi support layer preset prompts out of the box?

Yes. Installing with `pi` adds prompt templates under `.pi/prompts/` alongside `.agents/skills/archray/` so both `/archray` and `/skill:archray` work cleanly.

Will running update overwrite my curated graph.json or view.json?

No. Both `update` and default `uninstall` preserve `.archray/graph.json`, `view.json`, and your built `index.html`. Only `uninstall --purge` deletes user-generated maps.

Can I still build views manually from existing JSON without an AI host?

Yes. Once `.archray/graph.json` exists, run `./.archray/archray validate` and `./.archray/archray build` directly offline with zero AI agent or network connection.
