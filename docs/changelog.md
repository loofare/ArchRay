# Changelog

## v0.6.0（2026-11-19）

- **Style B 3D 空间全景 + 2D Bento 视觉重塑**：新增默认 3D 空间全景视图（四象限分离核心纵轴、异步/AI 侧翼、外部服务轨与底座，修正透视俯仰方向与分层画家遮挡排序，同层连线采用立体拱起贝塞尔曲线并带方向箭头，智能避让楼层与节点标签），同时重做 2D Bento 版图（平滑贝塞尔圆弧连线、超宽单层自动多行 Bento 网格重排、右翼外部虚线边界区）。
- **VisionOS 悬浮导航与可交互总览**：重排顶栏控制岛消除桌面端碰撞；新增拓扑/健康度/可替代性 `?` 帮助说明；健康度与可替代性总览支持拖拽、折叠、关闭与一键恢复；支持 3D/2D 完整无裁切“整图 PNG”导出与带离线开源二维码的分享海报导出；增强中英文全量双语校验与切换。
- **编码防护与乱码拦截**：CLI 读取 `graph.json` 自动兼容 UTF-8 BOM、UTF-16 LE/BE BOM 与 GB18030 中文解码，HTML 数据内嵌对非 ASCII 字符执行 `\uXXXX` 安全转义；校验器（`validate` / `build`）主动拦截 `\uFFFD` 替换符与 `????` / `API ??` 类问号占位符；`SKILL.md` 与 `/archray` 指令明确要求无 BOM UTF-8 写入。

## v0.5.1（2026-11-18）

- 修复默认楼层/等轴视图中节点标签随缩放计算失真问题，`autoZoom` 按当前投影包围盒计算，缩略图视口框与点击同步支持旋转。
- 斜杠命令与文档补齐 `--force` 用于重建派生的 `.archray/index.html`；详情页参考链接严格限制 `http:`/`https:` 协议；`SKILL.md` 统一全球唯一节点 ID 与 19 种已知 `kind`。
- 自更新链路拒绝非本地明文 `http://` 与跳转降级，增加超时/体积限制，并在解压前预检归档路径与条目类型；引导脚本修复 POSIX `sh` `shift` 参数处理与正则转义。
- `install` 失败回滚清理新建空目录并恢复文件权限；`uninstall` 精确清理所选宿主空目录并对未安装宿主给出明确提示；`doctor` 增加 `tar` 可用性检查。
- 纳入 `cli/` 与 `scripts/*.ts` 类型检查（`tsconfig.cli.json`）并新增 Ubuntu / macOS / Windows GitHub Actions CI。
